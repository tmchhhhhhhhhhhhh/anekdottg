# 🤖 AnekdotTG

**Telegram bot for sharing jokes (anekdot).**  

A simple Python Telegram bot that sends random jokes on command. Lightweight and easy to deploy.

---

## 📌 Features

- 😂 Send random jokes  
- 💬 Commands for interaction:  
  - `/start` – welcome message  
  - `/anekdot` – get a random joke  
  - `/help` – list of commands  
- 📝 Easy to extend with more jokes or commands  
- 🐍 Python + aiogram
